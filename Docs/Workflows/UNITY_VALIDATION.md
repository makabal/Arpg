# Unity 验证清单

凡是涉及 Scene、Prefab、Animator、AnimationEvent、输入、UI 序列化引用或资源导入的改动，都不能只靠静态代码判断完成。

## 基础检查

- [ ] Unity Console 无 C# 编译错误。
- [ ] 没有新的 Missing Script。
- [ ] Prefab 引用正常。
- [ ] Scene 引用正常。
- [ ] 新增 Sprite、Animation、SO 等资源导入配置正确。
- [ ] 对应 `.meta` 文件未异常重建。

## Play Mode

根据任务至少验证：

- [ ] 原功能没有明显回归。
- [ ] 新功能的正常路径可用。
- [ ] 输入按下、持续、松开等状态正确。
- [ ] 冷却、资源消耗、状态切换等运行时数据正确。
- [ ] 禁用对象、死亡、中断等异常路径不会卡住状态。

## 当前技能相关重点

- 数字键 `1–6` 与六槽映射正确。
- 鼠标点击技能槽与键盘输入走同一技能流程。
- 持续技能按住与松开正确。
- 冷却显示与 `SkillRuntime` 一致。
- UI 不自行实现战斗规则。

## 验证结果描述

必须区分：

- **静态确认**：只阅读代码/资源。
- **编译确认**：已确认 Unity 无编译错误。
- **Play Mode 验证**：已实际运行。
- **未验证**：当前环境无法执行。

禁止把“理论上可运行”写成“已验证”。
