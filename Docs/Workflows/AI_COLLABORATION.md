# AI 协作开发规范

本规范定义开发者、GPT-5.6 Sol 与 GPT-5.6 LunaMax 在本项目中的强制协作方式。

## 1. 开发者确认优先

除非开发者明确表示“不需要确认”或“直接执行”，否则任何功能或代码变更在开始实际修改前，都必须先得到开发者确认。

适用范围包括：

- 新功能。
- Bug 修复。
- 行为修改。
- 重构。
- 数据结构调整。
- Scene / Prefab / ScriptableObject 等运行时资源修改。
- 架构或职责调整。
- 删除、替换现有实现。

确认单位默认为一个明确的“变更任务”或“变更批次”，不要求逐行、逐文件确认。

如果已确认的任务在实现过程中需要明显扩大范围，必须停止扩展并重新交给开发者确认。

## 2. Codex 模型分工

Codex 任务采用以下分工：

```text
GPT-5.6 Sol
主管：需求理解、任务规划、任务拆分、指令编写、结果审查
        ↓
GPT-5.6 LunaMax
执行：具体代码与资源实现、自检、结果回报
```

### GPT-5.6 Sol

Sol 在开始任务前必须：

1. 阅读 `PROJECT_OVERVIEW.md`。
2. 阅读 `CODEX_BRIDGE.md`。
3. 阅读与任务相关的 `Docs/` 规范与架构决策。
4. 阅读实际相关代码和资源。
5. 理解目标、边界、非目标和验收状态。
6. 判断任务是否需要拆分。

简单任务无需为了形式强行拆分。

当任务涉及多个相对独立目标、多个系统、明显先后依赖或一次实现不利于验证时，由 Sol 拆分成多个清晰子任务。

## 3. 编码前任务清单

正式开始实现前，Sol 必须先向开发者展示一份简洁任务清单。

任务清单只需要体现：

- 要做什么。
- 做成什么样。

不需要提供具体代码步骤或冗长实现细节。

示例：

```text
1. 清理技能栏解锁逻辑
   完成后：技能栏只展示当前装备技能，不再判断解锁状态。

2. 简化 SkillSlotView
   完成后：只负责图标、冷却、快捷键和输入。
```

除非开发者已明确免除确认，否则展示任务清单后必须等待开发者确认，才能开始实际修改。

## 4. Sol 向 LunaMax 下发任务的要求

Sol 给 LunaMax 的实现指令必须规范、清楚、可执行，至少包含：

- 目标。
- 当前背景。
- 本次包含。
- 本次不包含。
- 必须遵守的项目规范。
- 验收结果。
- 建议关注文件。

禁止只给出“把这个修一下”“完善一下技能栏”之类模糊指令。

LunaMax 必须先阅读相关现有代码，再开始修改，不能只机械编辑 Sol 指定的文件。

## 5. LunaMax 实现边界

LunaMax 负责具体实现，并必须：

- 严格遵循 Sol 下发的任务范围。
- 优先复用现有系统。
- 不主动扩大需求。
- 不进行无关重构。
- 不自行改变已确认架构。
- 完成后执行能够执行的静态检查、编译或测试。
- 明确标记无法在当前环境验证的内容。

如果发现任务必须扩大范围才能完成，应停止扩展并反馈给 Sol，由 Sol 判断是否需要重新交给开发者确认。

## 6. Sol 主管审查

LunaMax 完成后，Sol 必须进行主管级审查，至少检查：

- 是否符合原始需求。
- 是否超出任务范围。
- 是否符合 `Docs/` 中的规范和架构决策。
- 是否出现重复实现或不必要重构。
- 是否破坏相关已有功能。
- 是否满足验收标准。
- 验证声明是否真实。

“理论上可运行”不能写成“已验证”。

涉及 Unity Scene、Prefab、Animator、AnimationEvent、序列化引用等内容时，必须区分静态检查与实际 Unity Play Mode 验证。

## 7. 完整执行顺序

```text
开发者提出需求
        ↓
Sol 阅读项目并理解需求
        ↓
Sol 判断是否需要拆分
        ↓
Sol 给开发者任务清单
        ↓
开发者确认
        ↓
Sol 给 LunaMax 下发规范任务
        ↓
LunaMax 实现 + 自检
        ↓
Sol 主管审查
        ↓
必要的 Unity / 编译 / 静态验证
        ↓
同步更新 PROJECT_OVERVIEW.md
        ↓
Git Commit / Push
        ↓
CODEX_BRIDGE → REVIEW
        ↓
ChatGPT / 开发者验收
        ↓
ACCEPTED
```

如果开发者明确表示“不需要确认”，只跳过等待确认步骤，其余规则仍然执行。
