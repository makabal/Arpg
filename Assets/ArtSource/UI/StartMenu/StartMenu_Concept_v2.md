游戏名由用户于 2026-10-22 确认为「青林物语」。本文件记录设计方案；Unity 场景与动画尚未实现。

## 动态分层方案（待实现）

| 图层 | 表现 | 建议节奏 |
|---|---|---|
| 森林背景 | 保持稳定，避免影响菜单阅读 | 静态 |
| 前景树叶 | 轻微视差，不移动按钮与标题 | 最大位移约 4–8 像素 |
| 落叶 | 少量叶片沿斜线缓慢飘落，避开主要文字 | 每片约 8–14 秒；错开起始时间 |
| 光斑 | 半透明光斑轻移并缓慢改变透明度 | 约 6–10 秒循环 |
| 骑士 | 复用现有 Warrior_Idle 待机资源 | 按已有动画帧率播放 |
| 主按钮 | 悬停提亮边框，按下轻微下移 | 反馈约 0.1 秒 |

实现时需要将背景、空白标题牌、按钮底图、角色和动态叶片分别制作或导出。不可直接将含骑士与菜单文字的整张效果图叠加动画，以免出现双重角色或无法独立交互的按钮。文字应独立于底图渲染。
