# 青林物语 · 标题方向比较

用户认为先前标题仍不协调，本轮比较标题的整体设计，而非只替换字体颜色。

- A：林间木牌，叶片与标题结合。
- B：独立标题标志，剑与枝叶呼应冒险主题。
- C：绿色悬旗，两行标题与骑士结合。
- 输出：`StartMenu_TitleDirections_ABC.png`。
- 参考：项目原有场景概念和由 Fusion Pixel 12px 字体实际渲染的字样图。
- 工具：内置 ImageGen；本轮是标题美术探索，不是直接使用 TTF 排字的运行时效果，尚未接入 Unity。
