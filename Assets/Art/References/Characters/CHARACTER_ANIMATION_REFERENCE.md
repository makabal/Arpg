# Character Animation Reference

## Master prototype

`Warrior_Black_MasterPrototype.png` is the required source of truth for all player skill animations.

Related original animation references:

- `Warrior_Black_Attack1_Master.png`
- `Warrior_Black_Attack2_Master.png`

Do not redesign the warrior. Preserve the original pixel art and use source-pack animation frames whenever possible. Effects may be added around the character, but the helmet, plume, shield, sword, body proportions and pixel scale must remain unchanged.

For the Blade Storm skill specifically, `BladeStorm_UserAnimation_Master.png` is the approved animation and `BladeStorm_UserAnimation_Keyframe.png` is the approved icon keyframe reference.

## Default delivery

- 192×192 pixels per frame
- transparent PNG
- character and VFX combined
- horizontal sprite sheet plus separate frame PNGs
- point filtering, mipmaps disabled and compression disabled in Unity
