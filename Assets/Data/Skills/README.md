# Skill Assets

- `Definitions`: 完整技能定义。
- `Aiming`: 面朝方向、鼠标方向、选中目标等瞄准配置。
- `Deliveries`: 近战即时结算、投射物等效果传递配置。
- `Effects/Offense`: 伤害等进攻效果。
- `Effects/Defense`: 护盾、减伤等防御效果。
- `Effects/Recovery`: 治疗、资源恢复等恢复效果。
- `Targeting`: 自身、选中单位和范围目标解析配置。
- `Conditions`: 技能额外使用条件。
- `Triggers`: 被动技能触发配置。
- `Projectiles`: 远程技能使用的投射物预制体。
